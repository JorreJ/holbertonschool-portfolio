Key Features

Easy Book Registration

Register books in seconds with title, author, and ISBN — no complex setup needed.

Loan Tracking

Track loans and returns easily. Status updates help teachers and students know what's available.

Simple Search

Find books quickly with a flexible search by title, author, or other fields.

About the Project

Le Phare was inspired by my own experience during my civic service, helping manage a school library with no digital system. I wanted to create a simple tool to make library management accessible for small schools, without technical barriers or extra costs.
This project is part of my Portfolio Project at Holberton School.
